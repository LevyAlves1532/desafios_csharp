# 🚀 Desafios Práticos em C#

Este repositório reúne a resolução dos desafios práticos propostos durante meus estudos de **C#**. O objetivo foi colocar em prática os principais conceitos da linguagem, como entrada e saída de dados, manipulação de strings, operadores aritméticos, estruturas condicionais e formatação de datas.

## 📚 Desafios desenvolvidos

### 1. Boas-vindas personalizadas

Programa que solicita o nome do usuário e exibe uma mensagem de boas-vindas personalizada.

**Exemplo:**

```text
Digite seu nome:
Welisson

Olá, Welisson! Seja muito bem-vindo!
```

---

### 2. Nome completo

Programa que recebe o nome e o sobrenome separadamente e exibe o nome completo.

**Exemplo:**

```text
Nome: Welisson
Sobrenome: Silva

Nome completo: Welisson Silva
```

---

### 3. Operações matemáticas

Programa que realiza operações básicas utilizando dois valores do tipo `double`.

Operações realizadas:

* ➕ Soma
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão (com verificação para divisão por zero)
* 📊 Média aritmética

---

### 4. Contador de caracteres

Programa que recebe uma ou mais palavras e informa a quantidade de caracteres digitados.

**Observação:** os espaços podem ser desconsiderados na contagem, contabilizando apenas os caracteres válidos.

---

### 5. Validador de placa de veículo

Programa que verifica se uma placa segue o padrão brasileiro utilizado até 2018.

### Regras de validação

* Possuir exatamente **7 caracteres**;
* Os **3 primeiros** devem ser letras;
* Os **4 últimos** devem ser números.

**Exemplo:**

```text
ABC1234 → Verdadeiro
AB12345 → Falso
```

---

### 6. Exibição de data e hora

Programa que apresenta a data atual em diferentes formatos.

Formatos disponíveis:

* Data completa (dia da semana, dia, mês, ano, hora, minutos e segundos);
* Data no formato `dd/MM/yyyy`;
* Hora no formato de 24 horas (`HH:mm:ss`);
* Data com o mês por extenso.
